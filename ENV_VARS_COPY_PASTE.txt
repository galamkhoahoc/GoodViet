════════════════════════════════════════════════════════════════
  BACKEND ENVIRONMENT VARIABLES - COPY/PASTE
════════════════════════════════════════════════════════════════

Hướng dẫn:
1. Vào Vercel Dashboard → Backend Project
2. Settings → Environment Variables
3. Click "Add New"
4. Copy Name và Value từ dưới đây
5. Paste vào Vercel
6. Click "Save"
7. Lặp lại cho 7 biến

════════════════════════════════════════════════════════════════

-----------
Name:
MONGODB_URI

Value:
