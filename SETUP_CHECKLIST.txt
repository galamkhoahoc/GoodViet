□ BƯỚC 1: LẤY GEMINI API KEY (2 phút)

□ BƯỚC 2: ĐIỀN GEMINI KEY VÀO BACKEND (30 giây)
  
  1. Mở file: backend\.env
  2. Tìm dòng: GEMINI_API_KEY=your-gemini-api-key-here
  3. Thay bằng: GEMINI_API_KEY=AIzaSy...  (paste key)
  4. Save file (Ctrl+S)
  5. ✅ Done

□ BƯỚC 3: ĐIỀN MONGODB (TÙY CHỌN)
  
  Option A - Dùng MongoDB Atlas:
    1. Mở file: backend\.env
    2. Tìm dòng: MONGODB_URI=...
    3. Thay bằng connection string của bạn
    4. Save
    5. ✅ Done
  
  Option B - Dùng Local MongoDB:
    MONGODB_URI=mongodb://localhost:27017/goodviet
